## Содержание
В работе выполнены:
построение столбчатой диаграммы распределения по уровню образования родителей (parental level of education);
построение круговой диаграммы распределения по этническим группам (race/ethnicity);
построение гистограмм распределения для всех числовых столбцов (math, reading, writing score);
построение графиков тригонометрических функций y1=cos(2x) и y2=2cos(x) с настройкой цветов, сетки и легенды;
построение «ящика с усами» (boxplot) для math score и программное выявление выбросов по правилу IQR;
создание комбинированного графика (столбцы + линия) для столбца race/ethnicity;
вывод текста HELLO!!! средствами Matplotlib;
построение 3D-диаграммы рассеяния по трём оценкам с цветовым кодированием;
построение круговой диаграммы с процентами для образования родителей (только для юношей);
визуализация попарных зависимостей числовых признаков через pairplot (hist + scatter);
построение pairplot с KDE-графиками и кластеризацией по полу (hue='gender');
построение тепловой карты корреляций числовых столбцов;
формулировка итогового аналитического вывода по данным.
