# Лабораторная работа 2.1
## Базовый конвейер анализа данных в Pandas
**ФИО:** Богаткина Анастасия Андреевна
**Группа:** ЕТ-213
## Содержание
В работе выполнены:
формирование исходного словаря данных и преобразование в DataFrame;
сохранение таблицы в CSV-файл и загрузка обратно;
проверка структуры и типов данных (head, tail, info, shape, columns);
выборка столбцов и строк через iloc;
фильтрация заказов по нескольким условиям;
проверка качества данных и подсчёт пропущенных значений;
расчёт описательной статистики (mean, median, describe);
анализ распределения рейтингов через value_counts;
создание производного признака is_high_value;
группировка данных по каналу продаж и сортировка результата;
построение гистограммы распределения суммы заказов;
формулировка итогового аналитического вывода.
