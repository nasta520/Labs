# Лабораторная работа 4.1
## Лабораторная работа “Гипотезы”
**ФИО:** Богаткина Анастасия Андреевна
**Группа:** ЕТ-213
## Содержание
В работе выполнены:
загрузка файла Пренатальная диагностика.xlsx в DataFrame и проверка структуры данных;
подсчёт количества родившихся мальчиков и девочек;
расчёт и добавление нового столбца ИМТ (индекс массы тела) по формуле вес / рост²;
расчёт числовых характеристик для всех показателей (минимум, максимум, размах, среднее, медиана, стандартное отклонение);
визуальная проверка нормальности распределений через гистограммы с KDE для каждого показателя;
расчёт асимметрии и эксцесса для оценки близости распределений к нормальному (распределению Гаусса);
формулировка гипотез о гендерных различиях антропометрических параметров новорождённых;
обоснование выбора двухвыборочного t-критерия Стьюдента для независимых выборок (с поправкой Уэлча);
проведение t-теста для сравнения средних значений роста у мальчиков и девочек;
проведение t-теста для сравнения средних значений веса у мальчиков и девочек;
проведение t-теста для сравнения средних значений ИМТ у мальчиков и девочек;
формирование итоговой таблицы с t-статистикой, p-value и выводом по каждому показателю;
формулировка итогового аналитического вывода о наличии или отсутствии гендерных различий.
# Лабораторная работа 4.2
## Лабораторная работа «Т-тесты»
**ФИО:** Богаткина Анастасия Андреевна
**Группа:** ЕТ-213
## Содержание
В работе выполнены:
загрузка файла Психология.xlsx в DataFrame и проверка структуры данных;
формулировка нулевой и альтернативной гипотез для каждого психологического показателя;
обоснование выбора двухвыборочного t-критерия Стьюдента для независимых выборок (с поправкой Уэлча);
разделение данных на группы юношей и девушек;
проведение t-теста для всех числовых показателей (статистика, p-value, вывод);
формирование итоговой таблицы результатов по каждому показателю;
сортировка показателей по p-value для выявления наиболее и наименее выраженных различий;
формулировка итогового вывода о том, где гендерные различия проявились сильнее всего, а где слабее.
